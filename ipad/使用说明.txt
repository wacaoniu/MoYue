墨阅 · iPad 版（网页应用 / PWA）
════════════════════════════════

这是墨阅的 iPad / iPhone 版本：一个纯网页应用（PWA），不需要 App Store，
添加到主屏幕后像原生 App 一样全屏使用、离线可用。书从「文件」App 导入，
解析和存储全部在本机浏览器里完成，不上传任何服务器。

系统要求：iPadOS / iOS 16.4 及以上（2023 年 3 月后更新的系统）。


一、安装到主屏幕（只需一次）
──────────────────────────────
1. 用 Safari 打开墨阅网址（部署后得到的 HTTPS 链接）
2. 点 Safari 工具栏的「分享」按钮（方形带向上箭头）
3. 滚动找到并点「添加到主屏幕」→ 右上「添加」
4. 桌面上出现「墨阅」图标，以后点它打开（自动全屏、离线可用）


二、导入图书
──────────────────────────────
- 打开墨阅 → 点右上「导入图书」→ 在弹出的「文件」App 里选择
  epub / pdf / txt / cbz 文件（可多选）
- 书保存在 iPad 本地存储里；删除：在书架上长按封面 → 确认
  （删除只影响墨阅书架，不动「文件」App 里的原书）


三、阅读操作
──────────────────────────────
- 点屏幕左 1/3：上一屏；右 1/3：下一屏；中间：收起/呼出菜单
- 文字书读到章末再点右侧 → 自动进下一章
- 漫画 / PDF：双指捏合缩放，双击复位
- 菜单里可切：主题（纸张/米黄/护眼/夜间）、字号、
  双页合并（左起/右起，日漫选右起）、宽页拆分、页间距
- 阅读进度、主题、字号每本书自动记忆


四、常见问题
──────────────────────────────
- 书会不会丢？书存在浏览器本地库里，正常使用不会丢；但「设置 → Safari →
  高级 → 网站数据」里手动清除、或恢复出厂会清空书架（原书还在「文件」App，
  重新导入即可）。已添加到主屏幕的应用存储受 iOS 保护，不会被自动清理。
- 内存小的老设备看超长 PDF：已做远页回收，若仍卡顿可分批导入。
- DRM 加密电子书不支持（任何正规阅读器都不支持）。


五、本地测试（电脑上）
──────────────────────────────
双击「本地测试.bat」（需装 Python 3），浏览器自动打开 http://127.0.0.1:8765
支持 EPUB / TXT / CBZ / PDF，与 iPad 版同一套代码。

也可把 www/ 目录部署到任何静态网站托管（GitHub Pages、Vercel 等），
根目录或子目录都可以（所有路径都是相对的）。


六、代码结构
──────────────────────────────
ipad/www/
├── index.html        # 界面（触摸交互 + PWA meta）
├── moyue-core.js     # 解析核心：ZIP/EPUB/TXT/CBZ（移植自 desktop/moyue_desktop.py）
├── app.js            # 书库(IndexedDB) + 文本(Shadow DOM)/漫画/PDF 三种阅读模式
├── sw.js             # Service Worker：离线缓存 + /z/ 虚拟文件系统（按需解压）
├── manifest.webmanifest
└── vendor/           # pdf.js（与电脑版同版本）
